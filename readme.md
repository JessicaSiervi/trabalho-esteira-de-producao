
# Meu Portfólio Profissional

![Status da Pipeline](https://github.com/JessicaSiervi/trabalho-esteira-de-producao/actions/workflows/pipeline.yml/badge.svg)

Portfólio profissional desenvolvido para a atividade prática de CI/CD.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Node.js
- GitHub Actions
- GitHub Pages

## Funcionalidades

- Apresentação profissional.
- Habilidades técnicas.
- Projetos desenvolvidos.
- Links para redes sociais.
- Layout responsivo.

## Automação CI/CD

O projeto utiliza GitHub Actions para:

- Validar o código através de Linter.
- Verificar arquivos acima de 500KB.
- Procurar termos proibidos.
- Verificar links e imagens.
- Executar testes em Node.js 18 e 20.
- Publicar automaticamente pelo GitHub Pages.

## Publicação

O site será disponibilizado pelo GitHub Pages.
